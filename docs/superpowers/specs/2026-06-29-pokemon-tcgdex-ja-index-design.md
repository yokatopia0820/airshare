# TCGdex日本語全件検索索引 設計

## 目的

公開中のスマートフォン向け仕入れ判定画面で、TCGdexに登録された日本語カードを通信待ちなしで名前・番号検索できるようにする。ひらがな・カタカナを同一視し、検索結果は24件ずつ表示する。価格や詳細情報はカード選択後に取得し、検索の網羅性と価格の有無を分離する。

## 前提と制約

- 公式ポケモンカードサイトのページデータ、画像パス、検索API応答は複製しない。
- データ元はMITライセンスで公開されているTCGdex cards-databaseと、TCGdex REST APIに限定する。
- カード画像ファイルは同梱せず、TCGdex APIが返す画像URLだけを利用する。
- TCGdexの日本語データには未翻訳・未登録カードがあり得るため、「日本語版全カード完全網羅」とは表示しない。
- 国内取引価格とeBay実売価格は、許可された数値データがある場合だけ利益計算へ使う。TCGplayer、Cardmarket、PriceChartingは海外参考価格のままとする。
- GitHub Pagesで動作する静的アプリを維持し、新しい本番依存関係や秘密情報を追加しない。

## 採用方式

### 1. 生成済み全件索引

`pokemon-market/tools/build-tcgdex-ja-index.mjs` が `https://api.tcgdex.net/v2/ja/cards` を取得し、検索に必要な項目だけを `pokemon-market/data/tcgdex-ja-index.json` へ保存する。

出力形式:

```json
{
  "schemaVersion": 1,
  "generatedAt": "ISO-8601",
  "source": "https://api.tcgdex.net/v2/ja/cards",
  "license": "MIT",
  "cards": [
    ["tcgdex-id", "日本語カード名", "カード番号", "https://assets.tcgdex.net/..."]
  ]
}
```

配列形式にしてキーの重複を避け、静的配信サイズを抑える。生成時に次を検証する。

- 1,000件以上、50,000件以下
- IDの重複なし
- ID、カード名、カード番号が空でない
- 画像URLは空文字または `https://assets.tcgdex.net/` のみ
- JSON全体が5MiB以下
- 認証情報に見えるキーやURLを含まない

### 2. 検索処理

アプリ起動後に同一オリジンの索引をバックグラウンド取得する。検索時は次の順序で結果を統合する。

1. 同梱価格スナップショットと端末キャッシュ
2. TCGdex日本語全件索引
3. 既知のTCGdex不足を補う小規模データ
4. TCGdexのオンライン検索

検索文字列はNFKC正規化、ひらがなからカタカナへの変換、大文字小文字の統一を行う。空白区切りの複数語はAND検索にする。索引行は既存カードモデルへ変換し、`tcgdexId` を保持する。

検索結果は最初の24件だけを描画し、「さらに表示」で24件ずつ追加する。新しい検索、検索クリア、レアリティ変更では表示上限を24件へ戻す。進行中の古い検索応答は現在の入力へ適用しない。

### 3. カード選択後の詳細取得

索引カードを選択した時だけ、既存のTCGdexカード詳細APIを呼ぶ。セット名、レアリティ、画像、TCGplayer/Cardmarket参考価格を既存カードへ統合する。通信失敗時も索引の名前・番号・画像URLを残し、仕入れ金額入力と外部価格確認リンクを利用可能にする。

### 4. オフラインと更新

Service Workerは索引JSONをアプリシェルへ追加し、バージョンを更新する。初回オンライン表示後は端末内キャッシュから検索できる。

索引更新は明示的な生成コマンドで行う。

```powershell
node pokemon-market/tools/build-tcgdex-ja-index.mjs
```

生成物には生成日時とデータ元を保存する。通常の画面アクセス時にTCGdex全件APIを繰り返し取得しない。

## UI

- 検索欄、件数、レアリティ6ボタン、カード一覧という現在の構成を維持する。
- カード行は画像、カード名、セットコード・番号、レアリティだけを表示する。
- 画像取得失敗時は固定サイズの「画像なし」表示へ戻し、壊れた画像アイコンを残さない。
- 索引読み込み中も補完データの検索結果を先に表示し、件数の後ろへ短く「検索中」と表示する。
- データ元、ライセンス、更新処理などの管理情報は店頭画面へ表示しない。

## エラー処理

- 索引JSONが取得できない場合は、現在の小規模補完とTCGdexオンライン検索へ自動フォールバックする。
- 索引形式が不正な場合は採用せず、画面を停止させない。
- TCGdex詳細取得や価格取得が失敗しても、検索・カード選択・外部価格確認リンクを維持する。
- GitHub Pagesではローカル専用PriceCharting APIを呼ばない。

## 検証基準

- 生成器の正規化、件数制限、重複、画像URL制限をテストする。
- 実索引が1,000件以上で、ID重複と公式サイト由来URLがないことをテストする。
- `かすみ` と `カスミ` が同じ結果を返し、「カスミのおねがい」「カスミの元気」を含む。
- 一般的なポケモン名で24件を超える場合、初期表示が24件で「さらに表示」が出る。
- 選択前に仕入れ金額欄を出さず、選択後だけ表示する。
- 375px、390px、430px、1365pxで横スクロール、文字重なり、44px未満の操作領域、コンソールエラーがない。
- `node --test`、構文検査、GitHub Pages公開後のブラウザ検証を通過する。

## 完了条件

TCGdex日本語索引が公開版へ同梱され、対応カードを端末内で即時検索できること。検索結果の件数が増えても24件段階表示が維持され、カード選択後の詳細・価格取得と既存利益計算が壊れていないこと。
