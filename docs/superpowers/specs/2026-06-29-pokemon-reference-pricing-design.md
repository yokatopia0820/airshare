# Pokemon Market Reference Pricing Design

## Goal

公開中の店頭検索画面で、取得できたTCGplayerまたはCardmarketの市場価格を円換算し、仕入れ額入力後に参考利益とROIを即表示する。

## Data Rules

- TCGdexのカード詳細に含まれるTCGplayerまたはCardmarket価格だけを自動利用する。
- TCGplayer価格はUSD、Cardmarket価格はEURとして当日為替レートで円換算する。
- eBay実売データではない価格を「eBay価格」と表示しない。
- eBay実売スナップショットがある場合は、従来どおりeBay価格と利益を優先する。
- 価格未取得時は金額を推定せず「価格未取得」と表示する。

## User Flow

1. カードを検索して1枚選ぶ。
2. 選択時にTCGdex詳細価格を取得する。
3. 価格がある種類には「海外参考価格」と円換算額を表示する。
4. 仕入れ金額を入力すると「参考利益 ○円」とROIを表示する。
5. 国内価格とeBay実売価格は各検索リンクから確認できる。

## Verification

- 参考価格でも計算でき、表示文言が「参考利益」になること。
- eBay実売データでは従来の「利益」表示を維持すること。
- 価格未取得を0円扱いしないこと。
- 375px、390px、430px、1365pxで重なりや横スクロールがないこと。
- 公開URLで検索、選択、価格表示、仕入れ額入力を確認すること。
